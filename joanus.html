Projekt JOANUS

An autonomous Python data science suite designed to identify, extract, and validate exoplanet candidates from NASA space telescope archives (TESS, Kepler, Roman Space Telescope). Engineering automated discovery pipelines ahead of the 2027 data drop.

PIPELINE ARCHITECTURE

Designed for multi-core headless batch processing, the pipeline executes rigorous signal ingestion and processing routines:

  • Signal Processing: Outlier removal, normalization, and Savitzky-Golay flattening of raw FITS lightcurves to eliminate thermal drift and stellar variability.
  • 2-Pass Blind Search: Automated Box Least Squares (BLS) periodogram execution with dynamic period constraints to bypass low-frequency noise. Escales to Deep Search only if required.
  • Batch & Persistence: Multi-target concurrent processing exporting physical telemetry directly to JSON databases.

RELATIV-FIRST METRIC

To analyze newly discovered stars lacking existing catalog metadata, JOANUS relies on the pure photometric radius ratio derived directly from the transit depth. This ensures robust characterization independent of existing astronomical databases.

\( \frac{R_p}{R_*} = \sqrt{\delta} \)

Where \( R_p \) is the planetary radius, \( R_* \) is the stellar radius, and \( \delta \) is the normalized transit depth. Fallback API lookups via Astroquery secure the pipeline against missing local FITS data.

VALIDATION SUITE

A multi-layered programmatic defense against false positives, isolating true exoplanetary transits from eclipsing binaries and instrument noise:

  • Odd/Even Depth Mismatch: Filters out eclipsing binaries masquerading as exoplanets by ensuring alternating transits remain identical (<15% deviation).
  • Secondary Eclipse Check: Analyzes Phase 0.5 for secondary light dips, flagging binary star systems.
  • SNR Thresholding: Automatically rejects candidate signals with a Signal-to-Noise Ratio below 5.0.
