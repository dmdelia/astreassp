Projekt JOANUS

An autonomous Python data science pipeline designed to identify, extract, and validate exoplanet candidates from NASA space telescope archives (TESS, Kepler, and future Roman Space Telescope datasets).

Data Pipeline Architecture

  • Signal Processing: Outlier removal, normalization, and Savitzky-Golay flattening of raw FITS lightcurves.
  • Blind Search: Automated Box Least Squares (BLS) periodogram execution.
  • Batch Automation: Multi-target headless processing exporting telemetry and physics data directly to JSON.

Relativ-First Metric

To analyze newly discovered stars lacking existing catalog metadata, the pipeline relies on the pure photometric radius ratio:

\( \frac{R_p}{R_*} = \sqrt{\delta} \)

This allows accurate physical characterization regardless of pre-existing stellar database entries.

Validation Suite

  • Odd/Even Depth Mismatch: Filters out eclipsing binaries masquerading as exoplanets.
  • Secondary Eclipse Check: Analyzes phase ranges for false positive light dips.
  • SNR Thresholding: Rejects background instrument noise automatically.
