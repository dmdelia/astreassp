01 / PROGRAM

Two disciplines.
One engineering approach.

ASTREA combines physical flight hardware with scientific computation. The program currently spans the ICARUS-RLV autonomous reentry testbed and JOANUS, an exoplanet detection and validation pipeline.

to near-space flight.

PHASE 0

Architecture & Bench

Flight software, sensor fusion, hardware interrupts and pipeline modularization.

PHASE 1

Local Drop Tests

Controlled 1,000 m drops to validate flight state machines, grid fins and recovery.

PHASE 2

Stratospheric Mission

Up to approximately 35 km with the full science payload.

PHASE 3

High-Altitude Pinnacle

Targeting approximately 40 km and ultra-thin atmospheric conditions.
