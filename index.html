MISSION ICARUS-RLV

A Balloon-Launched Reentry Vehicle (BLARV) testing deterministic C++/FreeRTOS flight software on ESP32. Featuring active aerodynamic control via Grid Fins and Cold-Gas RCS for autonomous Return-to-Launch-Site (RTLS) capability. Science payloads target the Pfotzer-Maximum radiation profile and astrobiology exposure.

PROJEKT JOANUS

An autonomous Python data science pipeline designed to identify, extract, and validate exoplanet candidates from NASA space telescope archives. Utilizing a Relativ-First metric, Box Least Squares periodograms, and robust False-Positive validation suites.
