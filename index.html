ASTREA SOLO SPACE PROGRAM

An independent aerospace initiative developing autonomous Stratospheric Reusable Launch Vehicles (ICARUS-RLV) and astrophysical data pipelines (Projekt JOANUS)[cite: 1].

Explore Missions

MISSION ICARUS-RLV

A Balloon-Launched Reentry Vehicle (BLARV) testing C++/FreeRTOS flight software on ESP32[cite: 1]. Featuring active aerodynamic control via Grid Fins and Cold-Gas RCS for autonomous Return-to-Launch-Site (RTLS) capability[cite: 1]. Scientific payloads include a Geiger-Müller counter for cosmic radiation at the Pfotzer-Maximum and dry yeast astrobiology stress tests[cite: 1].

PROJEKT JOANUS

An autonomous Python data science pipeline designed to identify and verify exoplanet candidates from NASA space telescope archives[cite: 1]. Utilizing a Relativ-First metric (Rp/R*), Box Least Squares (BLS) periodograms, and a robust Odd/Even depth validation suite to eliminate false positives[cite: 1].

FLIGHT MANIFEST

M-1 to M-2: Sub-atmospheric local drop tests validating Grid Fin precision[cite: 1].
M-3 to M-4: 35,000m stratospheric ascents capturing 4K optics, Pfotzer radiation, and astrobiological yeast exposure[cite: 1].
M-5 (Titan Pinnacle): 40,000m near-space flagship mission testing vacuum cold-gas RCS and full RTLS[cite: 1].
