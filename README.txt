ASTREA SSP website update

This package is flattened for easy Codespaces transfer.

Files that would normally be inside folders use + in their names:
- assets+site.css -> assets/site.css
- assets+site.js -> assets/site.js
- projects+icarus.html -> projects/icarus.html
- projects+joanus.html -> projects/joanus.html

Move all files into the repository root, then replace + with / in the four flattened paths.

The visual direction stays focused on ASTREA Solo Space Program, not a conventional portfolio.
The site keeps the existing technical aerospace aesthetic, adds stronger program identity, and clearly marks roadmap stages as current, planned, or long term.

No em dash or en dash characters are used in the website source.
