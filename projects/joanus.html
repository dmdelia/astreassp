PROJECT 02 / ASTROPHYSICS

JOANUS

Exoplanet discovery and validation pipeline.

PROGRAM STATUSDEVELOPMENT
01 / OBJECTIVE

Search first. Validate independently.

JOANUS processes space-telescope photometry to identify potential exoplanet transits without depending on pre-catalogued stellar parameters as its first step. The pipeline is designed for repeatable, headless processing and structured output.

02 / PIPELINE
01

RELATIVE PHOTOMETRY

Derive transit depth and radius ratio directly from relative light curves.

02

BLS SEARCH

Automated period identification using Box Least Squares periodograms.

03

VALIDATION

Odd/even consistency and secondary-eclipse checks reduce false positives.

04

PERSISTENCE

Batch processing with structured JSON telemetry for reproducible analysis.

03 / DATA
TESS

Primary public space-photometry source for development and verification.

KEPLER

Historical survey data used for cross-checking pipeline behaviour.

ROMAN

Architecture is developed with future Nancy Grace Roman data in mind.
