ASTREA SSP / ABOUT

Independent research.
End to end.

ASTREA Solo Space Program is an independent aerospace technology and data science research initiative based in Germany.

01 / APPROACH

Hardware, software and analysis belong to the same system.

The program focuses on building and testing complete technical loops rather than isolated demonstrations: embedded flight software connects to sensors and actuators; scientific payloads create data; analysis pipelines turn that data into measurable results.

01

MEASURE

Instrument the system and preserve useful telemetry.

02

VERIFY

Use controlled tests and independent validation wherever possible.

03

ITERATE

Use every test to reduce uncertainty in the next design cycle.

02 / ROADMAP

Current development

ICARUS-RLV is progressing through architecture, bench validation and planned controlled drop testing. JOANUS continues pipeline modularization, validation and data-processing development.
